ListenFlow 0.2.2 网页长文与统一安装版
====================================

一、版本与目录

1. 最新程序目录：%LOCALAPPDATA%\Programs\ListenFlow
2. 最新扩展目录：%LOCALAPPDATA%\Programs\ListenFlow\extension
3. 用户数据目录：%LOCALAPPDATA%\ListenFlow
4. Native Messaging Host 清单：%LOCALAPPDATA%\ListenFlow\NativeMessaging\com.listenflow.native_host.json
5. 扩展固定标识：chdkljcgemgeljdnfdnblbelfhmkkfbp
6. %LOCALAPPDATA%\Programs\ListenFlow-EdgeTest 只保留一个指向最新版扩展的兼容入口，供已经加载旧路径的 Edge 自动找到新版文件；其中不再包含旧程序。

二、安装与扩展更新

1. 解压整个压缩包，双击“安装 ListenFlow.cmd”。不需要管理员权限，也不会修改默认浏览器。
2. 安装器会停止旧 ListenFlow，覆盖安装桌面程序和 Native Messaging Host，迁移阅读历史，更新扩展文件并删除旧程序。
3. 如果安装时 Edge 已经打开，磁盘文件虽然已经更新，但 Edge 内存中可能仍运行旧扩展。请打开 edge://extensions/，在“ListenFlow 网页听读”卡片上点击一次“重新加载”；也可以关闭所有 Edge 窗口后重新打开。
4. 如果尚未加载扩展，请在 edge://extensions/ 开启开发人员模式，点击“加载解压缩的扩展”，选择：
   %LOCALAPPDATA%\Programs\ListenFlow\extension
5. 确认扩展版本为 0.2.2，标识为 chdkljcgemgeljdnfdnblbelfhmkkfbp。

三、长网页扫描验收

1. 打开 https://javaguide.cn/java/basis/java-basic-questions-01.html。
2. 右键选择“重新扫描并朗读网页正文”，确认页面提示扫描字数。该页面在本次真实测量中约为 2.9 万字符，页面改版会使数值变化。
3. 向页面后半部分滚动；如果网页追加了新正文，扩展会等待页面稳定后原子重建快照，并显示更新前后的字符数。
4. 确认后半部分正文可以朗读、高亮和左键定位。
5. 对导航、评论较多的页面优先使用“重新扫描并朗读网页正文”；只有需要连同侧栏文字一起读取时才选择“朗读页面全部可见文字”。
6. 虚拟列表中已经从 DOM 卸载的文字无法保留可靠原文范围；此类页面仍可能需要滚动加载后重新扫描。

四、播放与高亮回归

1. 确认 Xiaoxiao 开始朗读，当前句子直接在网页原文中高亮。
2. 连续点击多处普通正文，确认旧声音立即停止，最后一次点击生效。
3. 暂停后点击新位置，确认暂停期间不发声；继续后从新位置朗读。
4. 停止后，从桌面主界面点击播放，确认网页重新扫描并恢复网页原文高亮。
5. 右键“ListenFlow 语速”选择 +2、+4 或 +6，确认声音和高亮会话保持一致。
6. 链接、按钮、输入框、文本选择和页面手动滚动保持正常。

五、Edge 自带“大声朗读”与蓝牙耳机

ListenFlow 使用 Windows SAPI 默认音频设备，没有代码证据表明它会独占 Microsoft Xiaoxiao。Edge 自带“大声朗读”是 Edge 自己的播放会话，Windows 可以为 Edge 单独保存音量和输出设备。

连接蓝牙耳机后请执行：

1. 打开“设置 → 系统 → 声音 → 音量合成器”。
2. 启动一次 Edge 自带“大声朗读”，让 Microsoft Edge 出现在应用列表。
3. 确认 Edge 没有静音，并把 Edge 的输出设备设为蓝牙耳机或“默认”。
4. 完全退出 ListenFlow 后测试 Edge；再启动但不朗读测试；最后让 ListenFlow 朗读时测试。
5. 如果只有最后一种情况失败，请记录蓝牙耳机名称、Edge 音量合成器输出设备和失败时间，再导出诊断日志。

六、卸载与数据

双击“卸载 ListenFlow.cmd”会移除程序、通信宿主、快捷方式和扩展兼容入口，默认保留 %LOCALAPPDATA%\ListenFlow 中的阅读数据。安装器迁移旧验收数据前会在 migration-backups 中保留副本。

所有语音、正文提取、位置映射和诊断均在本机完成。自包含 EXE 不包含 Windows 语音包，电脑仍须安装可由 SAPI 使用的 Microsoft Xiaoxiao。
