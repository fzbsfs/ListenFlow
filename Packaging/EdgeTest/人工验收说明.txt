ListenFlow 0.2.0 Edge 人工验收版
================================

这不是正式发布版本，用于验证 Edge 原生右键菜单、网页原文高亮和点击定位。

一、安装

1. 解压整个压缩包，不要只单独运行压缩包内的脚本。
2. 保存当前朗读进度并关闭正在运行的 ListenFlow，然后双击“安装 ListenFlow.cmd”。安装不需要管理员权限，也不会修改默认浏览器。
3. 默认安装目录：%LOCALAPPDATA%\Programs\ListenFlow-EdgeTest
   该目录与原有 0.2.0 程序目录分开，不覆盖原程序文件。
4. 安装脚本会启动 ListenFlow，并打开 Edge 的扩展管理页和扩展目录。
5. 在 edge://extensions/ 开启“开发人员模式”。
6. 点击“加载解压缩的扩展”，选择：
   %LOCALAPPDATA%\Programs\ListenFlow-EdgeTest\extension
7. 确认扩展标识为：chdkljcgemgeljdnfdnblbelfhmkkfbp

Edge 不允许普通脚本静默安装解压缩扩展，因此第 5 至第 7 步必须由用户完成一次。

二、联网状态下的基本验收

1. 打开一个普通 http 或 https 网页。
2. 在正文空白处点击右键，选择“使用 ListenFlow 朗读网页正文”。
3. 确认 Microsoft Xiaoxiao 开始朗读，当前句直接在网页原文上显示黄色高亮。
4. 左键点击另一段普通正文，确认旧声音立即停止并从点击位置重新朗读。
5. 连续点击几处正文，确认只有最后一次定位继续朗读和高亮。
6. 右键依次测试暂停、继续和停止。
7. 暂停后点击另一处正文，确认不会提前发声；继续后从新位置朗读。
8. 点击链接、按钮和输入框，确认网页原有交互没有被无条件拦截。
9. 选中一段文字，右键选择“使用 ListenFlow 朗读所选文字”。

三、断网验收

1. 停止朗读并关闭 ListenFlow 与 Edge。
2. 断开网络。
3. 重新启动 Edge，打开之前已能离线访问的本地测试页或本地网络页面。
4. 重复正文右键朗读、原文高亮、左键定位、暂停、继续和停止。
5. 确认语音仍为本机 Microsoft Xiaoxiao。

扩展、正文提取、位置映射和语音播放均在本机完成。自包含 EXE 不包含 Windows 语音包，目标电脑仍须安装可由 SAPI 使用的 Microsoft Xiaoxiao。

四、卸载

1. 先在 edge://extensions/ 中移除“ListenFlow 网页听读”。
2. 从开始菜单运行“卸载 ListenFlow”，或双击安装包内的“卸载 ListenFlow.cmd”。
3. 默认卸载会保留 %LOCALAPPDATA%\ListenFlow 中的阅读进度和历史，并在存在旧宿主注册时恢复它。

当前已知边界：Edge 内部页面、扩展商店及禁止内容脚本注入的页面不能使用网页朗读。
