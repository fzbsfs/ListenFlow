# 0.2.3 本地语音开发验证记录

本记录描述开发工作区，不代表正式发布或所有验收条件通过。

## 代码与功能

- 在 `Speech/ISpeechService.cs`、`Speech/SapiSpeechService.cs` 中整理语音信息、中文优先排序、刷新和已知在线标识筛选。
- 在 `Core/ReaderController.cs` 中处理播放中及暂停时的语音切换、旧代次隔离和取消失败。
- 在 `MainForm.cs` 中提供语音选择、状态查看、刷新、试听和系统语音设置入口；保留暂不可用语音的文章记录。
- 更新协议、宿主、扩展及安装脚本的版本配置，并增加控制器、语音、窗口、存储、通信及网页逻辑测试。具体未提交文件以版本控制状态为准。

## 已执行的验证

- 开发环境为 Windows，使用本机 .NET 10.0.402 开发工具和 System.Speech 10.0.13。桌面测试编译并运行通过：77 项，失败 0 项；其中包含本机语音集成测试。
- 网页扩展静态及逻辑测试：40 项通过，固定扩展标识与本地依赖检查通过。这不是浏览器人工验收。
- 实际本机语音验证包括中文及英文语音切换、暂停切换、试听自然结束与停止、真实进度事件，以及隔离音频流中的暂停取消。英文和中文语音使用本机已经安装的语音。
- 独立临时目录中的跨进程测试验证了文章位置、可用语音以及暂不可用语音名称的保存恢复。
- 真实本地通信探针验证了宿主启动主程序、进度回传、暂停定位、继续、停止、复用和断线重连；测试数据使用独立临时目录。

## 未满足或未验证的事项

- 已知语音进度可能将同一数字的多个读音映射到同一原文范围，当前保守地从范围起点续读，可能重复切换点附近已经听到的内容。精确切换尚未满足用户提出的完全不重复要求；研究证据见 [语音切换位置研究记录](语音切换位置研究记录.md)。
- 内存音频流和事件测试不能证明实际音频设备缓冲中没有残留或重叠；真实设备听感尚待验证。
- 本版本的真实浏览器完整闭环尚未验证。此前启动隔离浏览器并联动桌面程序的测试被自动审批拦截，返回说明为“被策略拦截”。
- 本版本尚未完成断网冷启动与完整网页朗读验证。用户此前确认过 0.2.2 在本机使用小小语音可以断网朗读，不能将该结果直接当作 0.2.3 的新测试。
- 已知在线标识会被过滤，但不能仅凭名称或标识保证任意第三方语音引擎不联网；所选语音仍需断网验证。
- 未实际安装或卸载系统语音包验证刷新；已用现有语音模拟暂时不可用及重新可用的状态。
- 未提交或推送这些改动，未创建合并请求，未发布新版本；现有 0.2.2 安装包和用户数据未被本次修改覆盖。
