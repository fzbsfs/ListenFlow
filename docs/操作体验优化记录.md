# 操作体验优化记录

桌面操作优化沿用现有本地语音、播放控制器和网页通信协议。

## 已修改

- 第四轮增加正文右键的从此处朗读、朗读所选文字并返回原文、选区加入待听，保留复制、剪切、粘贴、撤销及全选。
- 第四轮增加重听当前句，朗读中回到句首，暂停时定位后保持暂停。鼠标操作正文会暂时关闭跟随，方便选字。
- 悬浮条的更多菜单可直接访问剪贴板、插播、待听队列、重听和返回原文。
- 修复正文编辑未同步时插播使用旧位置、恢复原文失败时丢失恢复入口、队列自动推进时移除错误项目的问题。
- 语音输入边界对补充区图形符号、表情和孤立代理项使用等长空格占位。原文、扩展区汉字、补充区字母保留，真实语音进度仍使用原始 UTF-16 偏移。
- 第四轮针对队列、选区、重听和字符处理共运行十八项自动检查，全部通过。实际用户环境能枚举小晓，空格片段与处理后的中文短句成功合成为内存波形，后半句的真实进度保持原文偏移。原崩溃全文已被用户后续内容替换，未复验同一段文字。初次隔离测试运行器连接失败，在实际本机重跑后通过。

- 第三轮增加本地文章插播剪贴板并返回原文，原先正在朗读则续读，原先暂停或停止则回到原文后保持安静。
- 第三轮增加本次运行内的待听队列，最多 20 项，支持去重、移除、手动播放下一项；停止或报错中止自动连读。
- 网页文档禁止自动插播恢复；网页读完也不会自动接管成队列。明确点击队列的立即播放入口会结束网页会话并播放本地队列。
- 第三轮新增五项模拟语音的操作测试全部通过，覆盖插播恢复、安静恢复、队列推进、停止撤销和旧完成回调隔离；不代表实际语音验收。

- 第二轮增加当前文章的来源类别和标题、最近文章列表的进度和日期。
- 第二轮增加 9 至 24 的正文字号调整并保存偏好；语音管理按钮默认收起，可按需展开，语音选择与语速保持直接可用。

- 主窗口使用同一个播放、暂停、继续按钮，并保留停止与前后句。
- 前后句导航在朗读和暂停时可用，沿用原控制器的取消与播放代次保护。
- 主窗口、悬浮条和网页调速入口统一执行速率变更；暂停时变更速率清空旧队列，继续后使用新速率。
- 增加跟随朗读开关与回到当前句。关闭跟随后不再移动文本选区和滚动位置；鼠标滚轮浏览正文自动关闭跟随。
- 主窗口可以直接打开悬浮条；悬浮条统一橙棕配色，提供前后句、文章名称、按钮提示。
- 悬浮条位置和跟随偏好存入用户数据目录的 desktop-preferences.json，文章与阅读进度文件不变。恢复位置时限制在当前屏幕工作区内。
- 排除备份目录、诊断产物目录中的源码，避免编译时误纳入主程序。

## 验收重点

1. 播放按钮随状态显示暂停或继续。
2. 朗读中连续跳句，最终只朗读最后目标；暂停中跳句和调速不发声。
3. 滚轮浏览其他位置不会被拉回，点击回到当前句恢复跟随。
4. 移动悬浮条后关闭重开，位置恢复；拔掉副屏后控制条仍出现在可见屏幕内。
5. 网页朗读中使用桌面控制后，网页高亮继续跟随实际语音进度。
