主程序已有自身文本框内的当前句选择显示。未来 Edge 阶段的网页原文高亮是独立交付要求，必须显示在网页原有文字上，并由实际 SAPI 进度驱动；不能用字符位置日志或 ListenFlow 窗口内高亮替代。
