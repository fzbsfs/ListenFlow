# ListenFlow 0.2.1 网页扫描与会话改进报告

## 用户问题与确认原因

- 网页正文只使用单一 Readability 映射结果，缺少读取当前页面全部可见文字的入口。
- 桌面播放停止后，扩展后台删除会话，网页内容脚本也清除活动快照；此时桌面主界面再次播放仍会朗读旧正文，但网页已没有接收进度和更新高亮的会话。
- 网页右键菜单没有语速命令，网页启动命令也没有指定更快的默认语速。

## 0.2.1 修改

- 智能正文提取同时比较 Readability 结果与页面中字符数最多的 `article`、`main` 或 `role=main` 区域，使用覆盖更多正文的可靠 DOM 映射。
- 新增“朗读页面全部可见文字”，读取当前 DOM 中全部可见、非控件、非脚本文字。
- “朗读网页正文”改为“重新扫描并朗读网页正文”，每次执行都会重新生成快照并显示扫描字符数。
- 停止和完成后保留网页会话但清除高亮。用户在桌面主界面再次播放时，网页端检测该状态转换，重新扫描当前网页，以同一会话原子替换旧快照，然后继续接收真实 SAPI 进度和更新原文高亮。
- 页面正文节点变化时停止声音并标记快照失效；再次播放时重新扫描，不继续使用失效 DOM 映射。
- 右键菜单增加 0、+2、+4、+6 四档语速。默认语速由 0 调整为 +2；朗读中切换语速会取消当前队列并从当前字符位置按新语速重建队列。
- 产品与扩展版本统一为 0.2.1。安装器替换同一安装目录中的旧构建，并删除旧版开始菜单快捷方式。

## 自动化覆盖

- 协议验证：`set-rate` 仅接受活动会话和 -10 至 +10 范围。
- 路由验证：语速命令进入唯一桌面播放核心。
- 网页会话验证：停止后仍能收到桌面再次播放事件，并触发新快照。
- 页面提取验证：智能正文选取最长语义正文区域；完整页面模式包含智能正文以外的可见文字。
- 菜单验证：完整页面、重新扫描和四档语速均已注册。
- 安装验证：旧快捷方式被移除，0.2.1 快捷方式建立，重复安装与卸载保持幂等。
