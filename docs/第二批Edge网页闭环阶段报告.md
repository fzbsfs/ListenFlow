# ListenFlow 第二批 Edge 网页闭环阶段报告

## 范围

本阶段在已提交的通信基础设施 `b02f830` 之上实现 Edge Manifest V3 扩展。语音仍由唯一的 ListenFlow 主程序和现有 Microsoft Xiaoxiao SAPI 播放核心负责，扩展与 Native Messaging Host 均不包含第二套语音引擎。

第一批人工验收工具未在正文区域视觉高亮当前语句的问题，继续作为该独立测试工具的已知 UI 限制记录。本阶段没有据此重写播放核心；网页高亮由扩展独立实现。

## 实现内容

- 固定扩展标识和 Native Messaging Host 身份。
- 网页右键菜单命令：朗读所选文字、朗读网页正文、暂停、继续、停止。
- Mozilla Readability 0.6.0 本地固定副本，用于正文候选提取；运行时不访问网络。
- 正文快照保存原始 DOM 文字节点、节点内偏移和全局 UTF-16 偏移。
- 实际 SAPI `progress` 事件映射回原网页 DOM Range，并以当前句为单位高亮。
- CSS Custom Highlight API 样式可见时优先使用；样式在扩展隔离执行环境中不可见时，使用同一 DOM Range 的无交互覆盖层。
- 指读模式下左键点击普通正文定位；链接、按钮、输入框、可编辑区域与空白位置不拦截。
- 暂停期间定位只更新目标；继续后从新位置接收真实进度。
- `sessionId`、`snapshotId`、`snapshotVersion`、`commandSeq` 与 `playbackGeneration` 共同隔离旧消息。
- 标签页关闭、导航、正文节点变化和通信断开时清理会话或报告可恢复错误。

## 实际验证环境

- Edge：154.0.4258.37。
- 页面：本机 `127.0.0.1` 测试页。
- 浏览器网络：启动参数禁止后台网络，并把除 `127.0.0.1` 外的主机解析到不可达地址。
- 本地链路：Edge 扩展 → Native Messaging Host → 命名管道 → 唯一 ListenFlow 主程序 → Microsoft Xiaoxiao SAPI。
- 主程序与宿主均为本仓库 Release 构建。

## 测试中发现并修复的问题

首次真实截图显示 CSS Custom Highlight registry 中存在正确 Range，但扩展隔离执行环境返回的伪元素背景为透明，页面没有可见黄色背景。现在高亮器会检查实际样式；不可见时立即使用同一组 Range 的矩形覆盖层。修复后截图明确显示网页原文上的黄色背景和下划线，停止后覆盖层清除。

## 当前边界

- `edge://`、扩展商店、浏览器设置页及其他禁止内容脚本的页面不支持。
- 跨域 iframe 只能在用户实际右键所在的可注入 frame 内启动会话。
- 动态修改已映射正文时停止会话，暂不尝试对变化后的 DOM 做模糊重映射。
- 当前保证句级高亮；不承诺逐词进度。
- Readability 只负责选择正文候选，最终朗读文本仍从原始活动 DOM 文字节点构建，因此高亮不依赖克隆文档中的字符位置。

## 下一项人工验收

在普通网页正文上实际右键，确认菜单中出现“使用 ListenFlow 朗读网页正文”，点选后观察黄色原文高亮；随后左键点击另一句并听辨旧声音是否立即停止。该项通过前，不把浏览器原生右键入口标记为最终验收通过。
